## Zásada jednoduchosti

Veřejný hráč nemá být nucen číst rozhodcovskou specifikaci před první hrou.

Když je potřeba přidat složité pravidlo, nejprve zvaž:
1. zda má být vůbec součástí veřejné hry,
2. zda jej lze uzavřít jednoduchou tabulkou v kvazitaháku,
3. zda nejde jen o hraniční případ pro rozhodcovskou specifikaci.
