# Governance – index

## Základní princip

Josef Bukovský rozhoduje finální produktové a pravidlové otázky.

Agenti připravují analýzy, varianty, nálezy a implementační návrhy, ale nemají nahrazovat explicitní rozhodnutí implicitním předpokladem.

## Soubory

- `decisions.md` – stabilní shrnutí přijatých rozhodnutí
- `open-issues.md` – index aktuálního backlogu
- `decision-workflow.md` – životní cyklus rozhodnutí a pravidla pro agenty
- `glossary.md` – slovník pojmů

## GitHub Issues

Aktuální detail otevřených témat je v GitHub Issues.

Používané prefixy:
- `[DECISION]`
- `[AUDIT]`
- `[IMPLEMENTATION]`
- `[META]`

## Co je důležitější než tento adresář

Tento adresář není normativní herní specifikace.

Pokud governance shrnutí odporuje aktuálním normativním pravidlům, opravuje se governance shrnutí.
