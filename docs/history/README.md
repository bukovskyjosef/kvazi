# Historie vývoje pravidel

Tento soubor shrnuje hlavní směr dosavadních revizí. Aktuální stav vždy určují normativní dokumenty a `docs/governance/decisions.md`.

## První velká revize

Zaměřila se hlavně na formální mezery a možné exploity. Výsledkem bylo zpřesnění znakového řetězce, soutěžní identity, jediné závazné analýzy, valence, role kvaziautority, verzování a strukturovaného odevzdání.

## Druhá velká revize

Přesunula důraz k férovosti a veřejné hratelnosti. Vedla k uzavřenému soutěžnímu syntaktickému systému, uzavřeným morfologickým modelům, uzavřeným slovesným typům a valenčním rámcům, omezení nepravidelných skutečných slov, vzniku normativního kvazitaháku, interního morfologického katalogu a reachability auditu.

Současně se oddělila stručná veřejná vrstva, praktický kvazitahák a úplná rozhodcovská specifikace.
