# Kvazitahák – slovesa

> **Status:** architektura pravidla je rozhodnutá, konkrétní typy ještě nejsou navrženy.

## NORMATIVNÍ princip

Každé kvazisloveso musí mít:

1. jeden soutěžní časovací typ,
2. jeden povolený vid,
3. jeden soutěžní valenční rámec.

Časovací typ, vid ani valence se nevybírají z libovolných externích českých sloves.

## TODO – časovací typy

Je nutné vytvořit **malou uzavřenou sadu soutěžních časovacích typů**.

Každý typ musí normativně definovat:

- podmínku lemmatu / infinitivu,
- přítomné tvary,
- osobu a číslo,
- relevantní tvary způsobu a času, pokud jsou soutěžně dosažitelné,
- případné standardní varianty,
- které tvary jsou pro soutěžní model skutečně přípustné.

Cíl není popsat kompletní českou konjugaci, ale vytvořit férovou a veřejně srozumitelnou soutěžní sadu.

## TODO – vid

Uzavřít normativní množinu povolených hodnot.

Předběžně se uvažuje zejména:

- nedokonavý,
- dokonavý,
- případně obouvidový pouze pokud bude vědomě schválen.

Vid sám o sobě nevytváří novou soutěžní identitu.

## Jeden token

V celé kvazivětě je právě jeden token plnovýznamového slovesa.

Pomocné slovesné tvary podléhají reachability auditu a nebudou prezentovány v hlavní vrstvě, pokud nemají soutěžně použitelnou realizaci.
