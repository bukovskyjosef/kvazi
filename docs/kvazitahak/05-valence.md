# Kvazitahák – valence

Valence není omezena malým whitelistem pádových rámců. Hráč deklaruje jeden valenční rámec a doloží jej konkrétním současným českým slovesem se stejnou valencí.

Každý obligatorní slot musí být ve větě realizován. Formulář před odesláním kontroluje úplnost struktury, nikoli jazykovou správnost zvolené valence.

Otevřená zůstává pouze technická reprezentace rámce, slotů a evidence ve formuláři a datovém modelu. Aktuální stav práce určuje GitHub Issues.
